# prompts/

Category-organized, frontmatter-tagged AI prompts. Find anything fast via **`SEARCH.md`**.

Layout: `prompts/<Category>/<kebab-case-slug>.md`. Copy **`PROMPT_TEMPLATE.md`** to add a prompt,
fill in the YAML frontmatter, then add a row to `README.md`. See **`FIND_AI_PROMPTS.md`** for the
workflow used to mine new prompts from x.com.

Each subfolder below is a category (created as empty placeholders; add prompt files into them).
